如何使用

  1. 准备兼容的 64 位 Java，安装版或解压版均可。Resolver 2.7 需要 Java 17 或更新版本。
  2. 下载并解压 ICPC Tools Resolver 稳定版。
  3. 下载并完整解压本页的滚榜包，将 Resolver 解压目录放入包内。
  4. 双击 start-resolver.cmd。脚本会检查 Java 并自动寻找 Resolver；找不到目录时会提示输入。
