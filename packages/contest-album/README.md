# HGNUOJ 比赛相册

独立的比赛照片展示和管理插件。浏览入口 `/albums`，沿用所在域的公告权限。

## 使用

- 按年份浏览、按比赛名称搜索；每页以 12 本为目标，按完整年份分页，同一年不会拆到两页。
- 获奖信息可选金牌、银牌、铜牌或不显示。配置后，卡片右下角和详情标题右侧显示统一的五角星矢量图标与奖牌名称；未配置时隐藏，卡片不再显示右上箭头。
- 有“创建公告”权限的用户可新建相册；作者需有“编辑自己的公告”权限，管理员使用“编辑公告”权限管理。
- 先填写名称、年份、可选日期和 Markdown 简介，再批量添加照片。相册默认草稿，可勾选公开展示。
- 支持 JPG、PNG、静态 WebP，单张 20 MiB、80 MP，每本最多 500 张，并受用户文件配额限制。
- 可设置封面、拖动或用按钮排序、编辑照片说明、移出照片。上传立即保存，封面、排序、移出和文字信息点击“保存相册”后生效。
- 浏览页使用 480 px 缩略图和懒加载；点开使用 1600 px 大图，支持左右方向键、手机滑动和原图入口。无脚本时照片链接仍能打开原图。
- 大图弹窗最大宽度 1800 px、高度为屏幕的 94%，照片按比例适应可用空间；放大加号使用居中的矢量图形。
- 详情页编辑按钮放在上方，与面包屑同行，和标题右侧奖牌信息右对齐。
- CSS 在页面 head 中以内容版本链接加载，避免插件脚本延迟导致刷新或切换年份时排版丢失。

## 安装与数据

在已安装 `@hgnuoj/image-preview` 和 `@hydrooj/ui-default` 的 Hydro 工作区中安装依赖，将本插件加入 `addon.json` 后重启。

相册存储在 MongoDB 的 `hgnu.album` 集合中，按域隔离；公开用户文件由 Hydro 原文件存储管理，预览复用图片优化插件。草稿限制相册页面可见性，上传文件采用 Hydro 公开用户文件机制。

已有公告可通过一次性整理建立相册，照片复用原 `/file/...` 地址。插件不会自动改写公告或推断比赛日期。关联相册具有 `source.discussion`、`source.section`、`source.fragment`，公告详情会显示相册入口，相册中保留对应章节链接。

移出照片、删除相册只修改相册信息，不删除可能被公告共用的原文件；上传的新照片可在用户文件管理中管理。删除相册为软删除。

保存、上传和删除使用 revision 检查，过期操作会提示刷新；照片来源不能通过保存表单替换为任意 URL，表单域和相册编号不能覆盖当前访问地址。
