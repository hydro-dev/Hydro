# 算法 Wiki 框架交接

本分支默认不带演示文章。第一次部署时，「Wiki」显示空目录。维护者可在「管理域 → 权限 → 常规」给指定角色勾选「编辑 Wiki 文章」，随后通过 Wiki 的「新建文章」和「管理目录」维护内容。普通读者没有编辑权限。

「管理目录」可集中调整左侧导航各文章的分类及顺序。数字越小越靠前；分类按其中最靠前的文章排列。网页编辑适用于当期域；右侧「本页目录」仍从 Markdown 正文的二、三级标题自动生成。文章地址在创建后不变。

文章和目录设置分别存在 MongoDB 的 `wiki.article`、`wiki.directory` 集合，启动或首次写入时自动创建。请在与生产版本相同的隔离实例中，用匿名、普通成员和授权角色分别验证查看、搜索、新建、编辑、目录排序和越权阻止，并确认旧的「帮助」「关于本站」和站内其他插件入口仍然可用。不要迁入测试库或 WSL 的预览文章。
