# 外站统计与排行榜交接

主榜合并校内 RP、题目、比赛、通过数，以及五个外站累计通过数、外站合计和「每日做题」。默认沿用校内 RP 排名，点击 RP、站点、外站合计或每日做题表头可切换排序。外站排序支持「全部成员」和「仅已同步」，完整范围在服务端筛选、排序后再分页。0 题排序在无数据之前。年级筛选中的「其他」对应无法从班级资料识别入学年份的成员。

- 绑定仅保存公开用户名或 UID，不收集外站密码或 Cookie。同一外站账号只能绑定到一个本站用户；当前不验证外站账号所有权。有争议时请管理员查看绑定，学校如需可信竞赛排名，应在开放前决定认领校验方式。
- 热力图用绑定账号可取得的记录和本站 AC 记录；牛客、洛谷、力扣没有每日明细。个人页公开显示所绑定的公开账号。上线前确认当前权限是否允许向访客展示完整成员的班级和姓名。
- 默认北京时间每天 21:00 开始排队更新；除真实绑定外不访问外站。首轮回溯有页数上限，后续按游标增量更新。默认每站每轮最多 2,400 次请求，使用 `HGNUOJ_EXTERNAL_DAILY_REQUESTS` 可调低。遇到明确限流暂停对应平台。可用 `HGNUOJ_EXTERNAL_SYNC=0` 在测试和首轮部署验收期间暂停外站请求。
- MongoDB 会自动建立 `external.oj.binding`、`external.oj.pause` 和 `external.oj.quota` 所需索引或集合，无需导入 WSL 数据。外站 HTTP 访问和服务文件保留生产配置。构建前端后重启应用以加载新产物，确认 CDN 把资源 URL 的查询参数计入缓存键。

综合排行榜中的「每日做题」列汇总五个外站相邻两轮成功同步的累计题数差值，周期为前一日 21:00 到当日 21:00。实际采样可能因排队、限流而延后，数据表示累计数变化。个人页日历继续按可信的首次通过时间统计。每轮请求配额也按 21:00 划分，跨午夜继续使用同一轮配额。原右侧独立榜和独立分页已移除，统一使用主榜排序与分页。

每条绑定的新增字段 dailySnapshot 原子保存本轮时间、累计数和增量，无需单独迁移。首次同步、间断超过一轮或累计数下降时重新建立基线。相同轮次重复执行保持首次样本，换绑和解绑会清除原账号基线。按每日做题排序时列出该年级全部可展示的成员，分页数量复用 pagination.ranking 配置。已知增量按降序排列，已知 0 之后再列出尚无有效增量的成员。后者保留内部 null 状态，界面暂显示 0，悬停显示「待更新」说明，不会伪造同步结果或写入基线。部分平台缺少本轮增量时只汇总可用平台，并以星号标注。修改后的查询兼容 MongoDB 5.0.9 / FCV 4.4。

维护者请从最新受保护主分支合并功能 PR，在同版本的隔离实例验证：匿名与普通用户权限、绑定与换绑、两种排行榜范围和单站排序、合并表格各列对齐与窄屏布局、生产 MongoDB 版本下的查询与索引、生产出口的五个平台小样本同步、低配额/429 时的续跑。
数据库验证同时检查 `featureCompatibilityVersion`。MongoDB 5.0.9 使用 FCV 4.4 时，`$lookup` 的 `pipeline` 无法与 `localField`、`foreignField` 混用。排行榜查询采用兼容写法。以下命令适用于独立的 MongoDB 5.0.9 / FCV 4.4 测试实例，测试会先确认兼容级别，再创建和清理独立测试库。

```bash
HGNUOJ_TEST_MONGO_URI=mongodb://127.0.0.1:27019 \
HGNUOJ_TEST_MONGO_FCV=4.4 \
node -r @hydrooj/register --test test/hgnu-ranking.spec.ts
```

回归检查公告、图片预览、比赛相册和本站的提交评测。先分批开放真实账号。若需回滚，先暂停外站请求并恢复旧代码和对应静态资源；无需删除新增集合。
